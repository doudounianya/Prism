# G4 共用业务页面与历史验收

验证日期为 2026-11-24。Codex 在 Windows 隔离目录执行仿真和回归。PLC HMI 使用回环 OPC UA 设备和从 G0 恢复的专用 MySQL 副本。飞拍使用独立的本机 SQLite 历史库。

## 页面与数据边界

- 两个宿主复用设备监控、实时报警、历史报警、报警分析、今日产量、生产日报、产量趋势和操作日志的 WPF 页面。工艺参数共用工作区，飞拍保留手动示教和双组时序，PLC HMI 保留原工艺字段与权限。系统设置共用页签和布局，各自填充软件及账户内容。
- 飞拍顶部有十个既定入口，原 MES 入口保持禁用。飞拍系统设置显示当前仿真身份和本机数据目录，PLC 保留原账户服务和可编辑软件设置。
- 只有飞拍仿真写入同一用户目录下的 `history.sqlite`。源数据由实际经过的飞拍时序和仿真信号提供。G3 已完成的累计次数保留，G4 按完成时间建立历史；旧检查点缺少日期的累计值不回填到班次。

## 飞拍历史与桌面验收

| 用例 | 实测 |
|---|---|
| 实时、历史和报警分析 | 断连时活动信号变为未知。对于跨 4 秒缺口的报警，查询只得到两段共 5 秒有效时长。裁剪到测试窗口后为 3 秒。跨进程会话间隔单独作为缺口，心跳稳定时连续区间正确累计 |
| 今日产量、日报、趋势 | 在北京时间 08:00 和 20:00 边界提供四条独立完成记录。第一生产日白班 1 件、夜班 2 件，第二生产日白班 1 件。按小时、班次、日期和趋势逐项一致 |
| 失败重试与唯一结算 | 工件从上班次开始，暂停并恢复后在下一班次确认完成。确认前计数为零，最终按同一工件 ID 计一次。再次读取旧检查点会核对已完成记录，数据库去重。两组事件、恢复事件及完成日志均可查询 |
| 导航与页面 | 验证十个入口、报警三页、生产三页、趋势到日报、示教与完成日志、设备状态、系统设置和现有共享控制页。保持原 UI 授权与 IO 只读回归 |

本机仿真和 D1 用例可从 `tests/FlyScan.Workflow.Smoke` 重放。界面用例在 `tests/SharedControlPages.Smoke` 和 `tests/SharedIo.Smoke`。数据采集、日志写入和运行状态不依赖工艺页显示。

飞拍流程与历史用例 61 项通过，共享控制及 G4 桌面用例 59 项通过，共享 IO 13 项通过。跨进程验证使用同一工件 ID，恢复后数据库只有一条完成记录。

## PLC HMI 升级与回退

从 G0 恢复同一份历史副本，加入独立校验样本 41 件白班和 17 件夜班。按 G3、G4、回退 G3 依次启动，每次 88 项通过，覆盖原登录、设备监控、调试权限、参数回读、停止握手、报警分析、生产日报、产量趋势、IO 重连、操作日志、设置和退出。各次均读取原报警记录，日报和趋势均返回 58 件。生产数据库与部署配置全程不参与本次验证。

## 构建与取证

Debug 和 Release 全量重建均为零错误。公共 WPF 程序集在两个宿主的候选输出中具备相同的 SHA-256。依赖检查覆盖 27 个项目、16 个无界面库，发现零项违规。原五套冒烟测试及飞拍 G3 的百次双组扫描回归通过。
