WPF 性能怎么查

DataGrid 可启用行/列虚拟化并回收容器，减少长列表需要创建的可视对象。表的滚动容器、布局约束和模板复杂度决定虚拟化能否有效工作。数据虚拟化则要看分页、按需读取或限量查询。优化时先分开观察查询、绑定、布局和渲染，再用可视化树核对元素个数。当前离线基准包含绑定与离屏布局，GPU 渲染和实机帧时间是另外的观测目标。

using Prism.Commands;

namespace Company.PlcHmi.Main.ViewModels;

public sealed class DeviceOverviewViewModel : BindableBase, INavigationAware
{
    private readonly IPlcRuntime _runtime;
    private int _deviceCount;

    public DeviceOverviewViewModel(IPlcRuntime runtime)
    {
        _runtime = runtime;
        RefreshCommand = new DelegateCommand(Refresh);
    }

    public int DeviceCount
    {
        get => _deviceCount;
        private set => SetProperty(ref _deviceCount, value);

    public bool IsNavigationTarget(NavigationContext context) => true;

    public void OnNavigatedFrom(NavigationContext context) { }

    Task.Run 把工作排入线程池。连接、轮询、帧分发和历史写入都有长期任务，各任务经过 await 后可能在不同工作线程继续。看任务的职责，比记线程编号更稳定。

    时间、事务、索引怎么落到代码上

    术语速查与继续阅读

    术语在本工程里的含义
    绑定在 WPF 中指 UI 与对象属性关联，在 PLC 中也可指逻辑点和物理协议地址的映射。先识别上下文。
    模式与状态模式说明运行方式，例如手动与自动；状态说明当前阶段，例如停止、调试、初始化或运行。
    快照与反馈质量在某一时刻读到的值及其有效性、时间和来源。最后确认值可作历史参考。
    心跳与会话心跳说明观测持续可用；会话边界帮助区分重启、断链和持续采样。
    连接代次连接身份的版本，用来过滤跨重连的旧请求和过时反馈。
    比较点 / PSO基于运动位置条件生成输出的相关概念。不同控制器的条件维度、资源和执行证据需分别查看。
    Checkpoint / WAL检查点表达进度；预先写入的日志用于恢复。PLC 本地历史日志、数据库事务进度和飞拍工件检查点分别有各自含义。
    离线替身 / 回环 / 实机分别验证纯逻辑、协议与本机装配、现场设备以及实际时序。

    项目内有分层、生命周期、发布和各阶段验收文档。遇到读码与记录不一致时，核对所处源码版本、测试条件和应用实际装入的配置。
